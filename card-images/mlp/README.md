# MLP Card Images

Store Kayou My Little Pony card photos here.

## How to upload a card image

1. Go to **github.com/claudeaispam-maker/melanies-binder**
2. Navigate to `card-images/mlp/`
3. Click **Add file → Upload files**
4. Drag your cropped card photo (JPG/PNG)
5. Name it something like `rainbow-dash-01.jpg`
6. Commit

## How to use in the binder

After uploading, the image URL will be:

```
https://claudeaispam-maker.github.io/melanies-binder/card-images/mlp/rainbow-dash-01.jpg
```

In the binder: tap empty slot → **Custom Card** → paste the URL into **"or paste an image URL"** → Save.

## Naming tips

- Use lowercase with dashes: `twilight-sparkle-05.jpg`
- Include the card number if you know it: `pinkie-pie-12.jpg`
- Keep it under 500KB for fast loading on mobile
