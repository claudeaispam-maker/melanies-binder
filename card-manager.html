GitHub Token

A personal access token is required to upload images. It's stored only on this device.

How to get a token

  1. Go to github.com/settings/tokens/new
  2. Select Fine-grained token
  3. Under "Repository access" pick Only select repositories → melanies-binder
  4. Under Permissions → Repository → Contents: Read and write
  5. Generate and paste here

About

Images are stored in the card-images/mlp/ folder in the melanies-binder GitHub repo and served via GitHub Pages.
